## 旧域名与主站：分别测试

Perplexity 在英文品牌题里能列出主站页面，但表示仅根据搜索摘要，无法确认新旧域名关系。为区分回答本身和网站的实际情况，本次另外测试了公开入口，未跳过证书校验。

| 入口 | 本次实际观察 |
| --- | --- |
| `https://pinmoo.top/`、`https://pinmoo.top/en/`、`https://www.pinmoo.top/en/` | 当前测试网络均在 TLS 握手校验阶段报主机名不匹配（`SEC_E_WRONG_PRINCIPAL`），未取得 HTTP 状态码，不能声称已经 301 到主站。独立网页读取也未取得这些旧入口，不能据此断言所有地区都收到同一张证书。 |
| `http://pinmoo.top/en/` | 返回 301，Location 是旧域名自己的 `https://pinmoo.top/en/`，不是新主站。从这个入口跟随后续跳转会遇到上述校验问题。 |
| `https://pinmooconsulting.com/en/` | 正常校验，HTTPS 200，服务端 nginx。另测主域证书名称为 `pinmooconsulting.com`，当前证书有效期到 2027-01-28（UTC）。 |
| 旧根域名 A 记录 | Google 公共 DNS 当次返回 `75.2.60.5`。DNS 能解析并不等于证书匹配，也不等于用户能到新站。 |

这是可复现的访问问题，不是 Perplexity 混淆域名的已证实成因。建议优先核对 Netlify 的旧根域名、www 绑定和实际下发证书，两个独立网络复验；只处理这两个旧官网入口。主站仍在阿里云，本次未改 DNS、证书、跳转或任何工具子域名。
