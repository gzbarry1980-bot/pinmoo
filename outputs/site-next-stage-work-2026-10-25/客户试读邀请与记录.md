# 品沐官网客户试读

用途：邀请5位可能购买品牌电商咨询的客户或团队成员，了解他们能否看懂官网并找到合适的咨询入口。测试结果匿名记录，不需要提供店铺数据或私人聊天记录。

## 可以直接发送的邀请

你好，我们正在优化品沐咨询官网，希望邀请你帮忙试读约10分钟。你不需要提前准备资料，只需按照自己的理解浏览，告诉我哪些地方看不懂或不好找。你的反馈用于改善网站，不会公开姓名和公司信息。方便的话，我发你几个简单问题。

官网：https://pinmooconsulting.com/

## 试读任务

请先独立完成，不提前解释网站栏目。可以使用手机或电脑，记录设备即可。

1. 看首页约30秒，说说品沐主要服务谁、能解决哪些问题，以及你觉得GEO在服务中处于什么位置。
2. 假设店铺有流量但成交少，找到你认为最合适的服务，并说说你预计能得到什么交付。
3. 找一个与你的经营问题有关的案例。说出案例中已完成了什么，哪些只是计划或示意。
4. 找到联系品沐的方式。手机上可以试复制微信号；电话只检查能否打开拨号界面，不必拨出。
5. 最后说出最不清楚或最想改善的一处，以及你是否愿意进一步咨询、原因是什么。

## 匿名记录模板

| 项目 | 记录 |
| --- | --- |
| 参与者编号与角色 | 例如 P01，品牌负责人；不要填写姓名、公司全称或电话 |
| 试读日期与设备 | 待填写 |
| 首页定位理解 | 参与者原话；不要由测试者代写 |
| 服务、交付、案例、联系是否独立找到 | 分项记录完成、需要提示或未完成 |
| 主要卡点及出现页面 | 待填写 |
| 意向与原因 | 自愿回答；不把未回答记为无意向 |
| 允许记录原话的范围 | 待填写；未经同意不公开原话 |

设计目标：5人中至少4人无需提示找到服务、相关案例及联系入口。这个数字是本轮可用性目标，不代表现有结果；人数不足时按实际记录，不补造样本。
