# 天猫店铺经营周报制作技能

本技能用于基于多源数据（生意参谋、推广报表、客服数据等）自动化制作面向品牌方的天猫店铺经营周报。报告采用“核心导读 → 专项诊断 → 下周清单”的叙事框架，注重数据深度与问题诊断，并自动生成12张统一风格的可视化图表。

## 工作流程

制作周报包含以下标准步骤：

1. **数据读取与清洗**：
   - 提取生意参谋数据（整体看板、商品、流量来源、访客、直播等）
   - 提取推广报表数据（区分生意参谋全站推广口径与计划报表口径）
   - 提取客服绩效数据

2. **数据分析与诊断**：
   - **净销售额视角**：必须从支付金额中扣除成功退款金额，计算净销售额。
   - **退款诊断**：排查高退款率商品，分析退款对经营的影响。
   - **流量与推广效率**：对比不同流量来源的UV价值；对比不同推广场景（货品全站、超级短视频、关键词、店铺直达）的ROI。
   - **老客价值**：分析新老客占比及复购趋势。
   - **直播与客服**：分析直播转化漏斗（播中vs播后）、客服响应时长及净销售额贡献。

3. **生成可视化图表**：
   - 使用 `scripts/make_charts.py` 生成12张品牌绿色系的专业图表。
   - 运行前需根据本周实际数据更新脚本中的硬编码数据（搜索脚本中的数据定义部分并替换）。
   - 确保图表输出目录（如 `charts/`）已创建。

4. **生成周报文档**：
   - 参考 `templates/report_template.md` 的结构与叙事逻辑，结合本周实际数据与图表生成 Markdown 格式周报。
   - 报告语气需客观专业，重点在于**结构性趋势判断**和**可执行的下周建议**（如选品、页面优化、投放调整）。
   - 即使部分数据（如某渠道ROI）不佳，也应结合背景（如新店、蓄水期）给予客观解释，避免过度负面评价。

5. **导出为PDF**：
   - 使用 `manus-md-to-pdf` 将 Markdown 转换为 PDF 文件交付用户。

## 目录结构与资源

- `scripts/make_charts.py`: 生成12张标准图表的Python脚本（需更新数据后执行）。
- `templates/report_template.md`: 完整的周报Markdown模板，包含所有图表的引用路径及标准章节结构。

## 注意事项

- **口径说明**：在推广数据分析中，必须明确区分“生意参谋口径”（如全站推广）与“计划报表口径”，避免品牌方产生困惑。
- **图表路径**：在生成PDF前，确保 Markdown 中的图片路径与实际生成的图表路径一致（建议在转换前将相对路径替换为绝对路径以确保PDF正确嵌入图片）。
- **字体与编码**：图表生成脚本已配置 `Noto Sans CJK SC` 字体，确保中文字符在图表中正确渲染。
