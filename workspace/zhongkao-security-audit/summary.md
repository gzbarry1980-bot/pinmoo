# 广州中考付费站点上线前安全复核

审计日期：2026-07-23（北京时间）

## 范围

- `server/zhongkao-access/` 账号、会话、订单与权益服务
- `guangzhou-zhongkao/unlock/` 解锁页面
- `zhongkao.pinmoo.top` 的 Nginx、systemd、文件权限、监听端口和 SSH 有效配置
- npm 生产及开发依赖审计

本次仅进行授权范围内的静态检查、配置检查和正常接口回归，没有进行漏洞利用、爆破或拒绝服务测试。

## 结论

当前版本适合以 `preview` 模式继续内部测试，不适合立即开启真实收费。账号和长期权益保存在服务端，支付与短信通道均为 `disabled`，现网不会创建真实支付或扣款。

已在本轮修复：静态文件从 `0666` 收紧为 `0644`；API 转发 IP 改为 Nginx 覆盖真实来源地址，避免伪造 `X-Forwarded-For` 绕过验证码限流；后端部署健康检查增加启动重试；API 增加独立速率与并发限制。

## 待处理发现

### High：本地数据构建依赖 `xlsx@0.18.5` 命中两个公开 advisory

- 证据：`package.json` 的开发依赖 `xlsx`，仅由 `scripts/zhongkao/data-lib.mjs` 在离线数据更新阶段使用。
- 影响：处理恶意构造的 Excel 文件时可能触发原型污染或 ReDoS；该包未随线上账号 API 发布，现网付费运行时不加载它。
- 处置：数据更新只接受广州招考办等可信官方文件；后续将解析流程隔离为低权限、限时进程，并评估替换或采用 SheetJS 官方安全版本。

### Medium：整机 SSH 与历史服务暴露需在真实收费前收紧

- 有效配置为密钥登录、密码登录已关闭，但仍允许 root 登录、X11 转发、TCP 转发，`MaxAuthTries=6`。
- 公网还监听 2912、8443、2096 等历史 Xray/x-ui 端口；本轮未主动探测这些服务，也未确认其业务必要性。
- `fail2ban` 当前未启用。
- 处置：另开维护窗口创建非 root 部署账号、验证回退登录后再禁止 root；核对并收敛安全组端口；按实际用途决定转发能力；启用 SSH 速率防护。不得在未验证备用登录路径时直接修改。

### Blocker：真实支付链路尚未接入和验收

- 尚缺微信支付商户参数、回调验签与解密、支付成功幂等入账、关单/退款处理和对账。
- 尚缺短信服务商、发送回执和生产验证码风控。
- 尚缺权益数据库的加密备份与恢复演练，以及隐私政策、付费协议和退款说明最终文本。
- 公众号关注换权益还缺微信服务器事件回调；取消关注同步撤销只应撤销 `follow` 来源权益，不得影响已付款权益。

## 已验证的防护

- API 仅监听 `127.0.0.1:8787`，公网只经 HTTPS Nginx 访问。
- systemd 使用 `www-data`、`NoNewPrivileges`、空 capability 和只读系统目录；仅数据库目录可写。
- 环境密钥文件为 `0600 root:root`，数据库目录为 `0700 www-data:www-data`。
- 手机号仅保存 HMAC 和末四位；会话只保存 token 哈希；Cookie 使用 `HttpOnly`、`Secure`、`SameSite=Lax`。
- POST 接口校验 Origin，SQL 全部使用预编译参数，订单按登录用户隔离，已有权益时拒绝重复购买。
- Nginx 启用 HSTS、CSP、点击劫持防护、API 限速和连接数限制。
- 生产运行服务没有第三方 npm 依赖；`npm audit --omit=dev` 未发现运行时依赖漏洞。
