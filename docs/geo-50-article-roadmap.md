# 品沐咨询 GEO 经营洞察 50 篇路线图

版本：2026-07-16
目标：形成 50 个可以独立回答客户问题、可被搜索引擎收录、可被 AI 引用并能承接咨询决策的常青知识页面。

## 发布原则

1. 不以一次性批量上线 50 篇为目标，按每周 2 篇证据型母内容加 1 篇支持型清单发布。
2. 每篇只解决一个主要搜索意图，避免标题换词和关键词互相竞争。
3. 统一使用 CEBA：Claim（直接结论）、Evidence（判断依据）、Boundary（适用边界）、Action（经营动作）。
4. 必须具备作者、发布日期、复核日期、直接回答、至少 4 个章节、至少 2 个 FAQ、服务内链和相关文章内链。
5. 案例只使用已核对的匿名文本。不得新增客户名称、可识别细节、未经复核数字、截图或绝对结果归因。
6. 人物、履历、项目数量、联系方式和价格属于事实闸门字段，未经负责人批准不得在新文章中放大。
7. `lastmod` 只在正文、结论、证据或主要结构发生实质变化时更新。

## 每篇发布闸门

- [ ] 主要问题与现有页面不重复，搜索意图唯一。
- [ ] 开头 120 字内给出可独立引用的直接回答。
- [ ] 至少 3 类信息增益：口径、表格、流程、边界、清单、计算方法或真实匿名案例。
- [ ] Evidence 说明使用什么数据或材料；Boundary 说明不适用条件和缺失数据影响。
- [ ] 不出现未经批准的项目数量、客户名称、人物履历、价格和结果数字。
- [ ] 相关服务和文章内链可以实际打开。
- [ ] Article、FAQPage、BreadcrumbList、canonical 和 sitemap 检查通过。
- [ ] `npm run verify:content`、双构建验证和移动端视觉检查通过。
- [ ] 发布后记录公开 URL、索引状态、固定探针日期和询盘来源字段。

## 复盘节奏

- 发布后 24 小时：检查页面、canonical、sitemap、机器索引和明显事实错误。
- 发布后 7 天：记录搜索词、访问、内容互动、询盘和是否获得 AI 引用。
- 每两周：根据 cited、correction、gap 清单调整下一批主题。
- 连续三个相同周期后，再判断类别提及率、引用率和询盘趋势。
