# 品沐咨询 90 天 GEO 内容与信源计划

## 原则

官网负责完整方法和事实源，平台内容负责被各自生态发现。所有内容使用同一公司名、品牌定位、作者身份和官网链接，但标题、开头和篇幅按平台重新组织，不做一稿机械群发。

## 第 1 月：建立基础事实与问题覆盖

- 公众号：发布《电商经营周报不是报表：品牌负责人真正要看的 7 个判断》。
- 知乎：回答“天猫店铺有流量但转化低，应该先检查什么？”
- 百家号：发布《支付金额增长但净销售额没增长，问题可能在哪？》
- 头条号：发布《ROI 高也不能马上加预算：电商投放复盘的四个前提》。
- 官网：将上述主题对应到现有经营洞察页，并补充作者、更新时间、适用边界和可复核来源。
- Listing：完成企业信息页、三家地图和公众号主页口径对齐。

## 第 2 月：增加真实证据

- 公众号：发布一篇脱敏经营周报走查，说明数据来源、口径、判断过程和限制。
- 知乎：回答“退款金额为什么可能高于当期成交金额？”
- 百家号：发布《天猫退款治理：商品、页面、客服、履约怎么分工》。
- 头条号：发布《直播有流量没成交，先别急着怪主播》。
- 客户联合案例：争取一篇客户授权、双方署名的案例；无法公开品牌时，不伪造名称和数字。
- 官网：发布一份可下载的电商周报字段清单或退款排查表。

## 第 3 月：进入推荐与对比问题

- 公众号：发布《电商顾问、代运营和自营团队，分别适合什么阶段》。
- 知乎：回答“品牌什么时候应该找外部电商顾问？”
- 百家号：发布《传统品牌从 0 到 1 做电商，先做什么、后做什么》。
- 头条号：发布《AI 电商工具能替代运营团队吗？哪些判断必须由人完成》。
- 行业媒体：以“行业共性问题 + 脱敏样本方法”投稿，不发纯品牌通稿。
- 复测：完整运行 40 题题库，比较三个月的提及率、引用来源和错误事实。

## 每篇内容的证据门槛

1. 开头 75 字内直接回答一个真实问题。
2. 至少写清数据或判断的来源、时间和适用范围。
3. 至少提供一个可复核步骤、表格或清单。
4. 结论注明边界，不做绝对增长承诺。
5. 作者统一为“鲍俊文（沐风、BarryBao），品沐咨询主理人”。
6. 结尾链接到对应官网知识页，不只链接首页。
