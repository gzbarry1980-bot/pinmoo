# PINMOO GEO audit - 2026-07-12

## Executive diagnosis

The primary bottleneck is discovery and authority, not keyword density.

1. Direct crawler access works: tested AI and search user agents receive HTTP 200 and complete static HTML.
2. Search discovery is weak: searches for `pinmoo.top` and the legal company name surface `pinmooconsulting.com` or unrelated entities instead of the Aliyun site.
3. The two domains expose identical visible Chinese content. Self-canonical tags are correct, but duplicate content still gives search engines little reason to index both domains independently.
4. The legal entity has almost no discoverable third-party corroboration. The site cannot create this authority by repeating its own claims.
5. The raw homepage previously exposed four animated trust figures as zero. Crawlers that do not run JavaScript received incorrect facts.
6. The Aliyun HTML response omitted an HTTP UTF-8 charset declaration. The HTML meta charset helps capable parsers, but the response header should also be explicit.

## Six-stage assessment

| Stage | Current finding | Priority |
|---|---|---|
| Discovery | robots and sitemap are reachable, but crawler-log evidence is not yet measured | High |
| Fetch | static HTML is complete and direct crawler requests return 200 | Pass |
| Retrieval | `pinmoo.top` is not reliably surfaced by search; `.com` dominates | Critical |
| Selection | only three insight articles and little third-party authority | Critical |
| Absorption | articles have direct answers and FAQ, but limited sourced data and quotable evidence | High |
| Conversion | contact path is visible; attribution of AI-origin inquiries is not measured | Medium |

## Next actions

1. Deploy the UTF-8 header, crawler allow-list, truthful static counters and crawler-report script.
2. Run `bash scripts/report-ai-crawlers.sh` on Aliyun and preserve the first baseline.
3. Submit the current sitemap in Google Search Console, Bing Webmaster Tools and Baidu Search Resource Platform.
4. After deployment, run `node scripts/submit-indexnow.mjs https://pinmooconsulting.com`.
5. Give the domains distinct roles. Recommended: `pinmoo.top` as the Chinese official and knowledge site; `pinmooconsulting.com` as the English/international site. Do not keep two identical Chinese sites indefinitely.
6. Build a verified entity network: consistent legal name and positioning on business directories, map listings, WeChat, Zhihu and suitable industry media.
7. Publish evidence-led material using real samples, dates, methodology, limitations and attributable sources. Do not invent client names or performance data.
8. Establish a 30-50 question baseline across brand, category, recommendation, comparison and problem-solving queries, then re-test monthly.
