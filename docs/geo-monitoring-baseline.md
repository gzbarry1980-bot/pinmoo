版本：2026-07-12

## 测试规则

- 每个平台使用同一批问题，每月测试一次。
- 同时记录 App 联网回答与 API 非联网回答，不混为一个指标。
- 品类题占 75%，品牌题占 25%。
- 每题记录：是否提及、出现顺序、描述是否准确、引用 URL、竞品、回答日期和截图。
- 单次波动不做结论，至少连续三轮观察趋势。
