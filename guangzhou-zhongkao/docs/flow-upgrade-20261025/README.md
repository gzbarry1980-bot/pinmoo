## 已上线功能

- 首页两个主要动作：生成志愿、查学校；目标学校的分值分析保留直达入口，工作区四种开始方式保留。

- 完整结果先显示评分和主要去向，再突出一个当前重点。资格问题、数据缺失和具体建议优先于通用政策提示；其他说明可展开。
- 本批未改录取概率算法或给方案统一加分；模型版本仍2.3。真实序列号和设备绑定未操作。
