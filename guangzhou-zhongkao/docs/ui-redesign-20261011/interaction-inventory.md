# 全站点击区域盘点（2026-10-11）

> 专家：UI Designer（像素君）｜复核：WorkBuddy  
> 数据来源：本地 Chrome 真实渲染截图 + 源码与运行时 DOM 校验（`app.js`、`dynamic-ui.js`、`experience.js`、`navigation.js`）。  
> 截图目录：`docs/ui-redesign-20261011/screenshots/`

## 盘点方法

1. 使用 `playwright-core` 调用本机 Chrome，在 `http://127.0.0.1:8137` 静态服务器下拍摄 390px 手机与 1440px 桌面全页截图。
2. 对首页、求证版（verify）、学校库（schools）、学校详情（schools/detail）、目标校（target）、我的（my）、解锁（unlock）等重点页面逐项检查：显示文字/组件、是否可点击、实际点击范围、触发去向、返回方式、改法。
3. 标记 5 类高频问题：
   - P1 假入口：看起来像链接/按钮，点击无动作或范围与视觉不符。
   - P2 按钮位置/层级不清：同一任务出现多个主按钮，或主次按钮混在一起。
   - P3 返回困难：返回去向不一致、依赖浏览器返回、返回后丢失上下文。
   - P4 触控区域不足：按钮/图标点击区小于 44×44px，或相邻操作间隔不足。
   - P5 信息层级混乱：字号零散、颜色滥用、说明卡伪装成入口。

## 共性问题汇总

1. **P1 假入口/伪按钮**：批次说明卡、详情折叠 summary、学校卡空白区、工作区摘要链接，视觉上像可点但实际范围不一致或缺少动作。
2. **P2 按钮层级混乱**：`coachAnalyze` 与 `analyzePlan` 重复、工作区底部 `workflow-footer` 与原始按钮并存、学校详情顶部多个同级按钮。
3. **P3 返回困难**：从 verify → 学校详情 → 返回时，`sessionStorage` 已保留位置但按钮文案不统一；部分页面只有浏览器返回可用。
4. **P4 触控区域不足**：学校卡操作按钮、筛选“清除筛选”、历史表格“查看来源”、部分小图标小于 44px。
5. **P5 信息层级/字号**：说明文字使用 13px 与 16px 正文混排，summary 中的 `<b>` 像按钮，部分链接对比度偏低。
