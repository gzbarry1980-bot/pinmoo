## 已完成的 UI 修复

1. 首页四种使用方式采用整卡链接，手机正常字号下首屏能看到全部四个入口。第一批保留“特长生／自主招生”两个独立入口；第二批及第三、第四批卡片的标题和说明可直接点击。手机批次卡片改为整行，消除窄列过度换行。
2. 普通高中模拟统一为“填写条件 → 调整志愿 → 查看结果”。当前步骤与用户实际查看位置同步；未生成评估时，结果步骤不可点击且显示原因。生成草案只到第二步，确认后才显示评估。
3. 手机固定显示当前步骤主操作：第一步生成／目标校分析，第二步确认评估，第三步保存。旁边提供返回首页／修改条件／调整志愿。复用原按钮和事件处理，不另造绕过权限的触发路径。
4. 手机操作栏与底部导航错开；桌面不显示手机导航。模拟软键盘视口收缩时隐藏浮动栏，收起后恢复，转屏时重置高度基准。
5. 学校列表点击主体直接进入完整学校档案；收藏、对比独立操作，不误开预览。修正升学表现卡片嵌套链接，增加独立“升学表现”入口。返回列表保留筛选条件及浏览位置；志愿中的学校链接仍可快速预览。
6. 标题／正文／备注统一为 24／16／14 三档，通过同一字号源继承；清除覆盖根字号的重复声明。按钮有键盘焦点提示，主操作和排序按钮达到适当触控尺寸；放大文字时按钮可换行。
7. 保存方案增加即时提示。填写进度文案与“确认志愿，查看评估”按钮名称一致。公共组件增加重复初始化保护，共享资源版本更新。
