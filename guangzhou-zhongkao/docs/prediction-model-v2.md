# 预测模型 v2.1（2026-07-29）

## 本次修正

- 自动生成方向方案时，同一学校体系默认只推荐一个校区或招生项目，避免同一所学校在不同志愿重复占位。
- 手工填报仍允许选择同一学校体系的不同独立招生代码，但方案评分会提示志愿分散度不足。
- 预测只抽取当前方案所有批次均有完整录取表、梯度线和分数段的历史年度。当前第三、第四批组合使用 2023—2026 年；缺失整个批次的数据年度不再按落选计入。
- 某校在个别可用年度缺记录时，使用同校或同校区最近年度记录，并按两年度官方分数段换算相对位次；这类补齐会降低置信度并扩大机会区间。
- 机会区间使用各可用年度的加权结果计算，包含该年度 0% 命中的情形，避免只统计“曾命中年度”造成偏乐观。
- 新增近年等位门槛跨度和末位志愿分布校准；跨度较大或经常第一志愿即完成计划的学校会自动降低置信度并放宽区间。
- 标准模拟和“高保真模拟”统一使用固定随机种子，保证相同输入可复现；高保真模式额外考虑估分波动、年际难度和临界投档不确定性。

## 规则边界

系统遵循广州普通高中“梯度控制线上志愿优先投档”的公开规则，并同时判断录取最低分、末位考生志愿序号、末位考生分数及同分序号。学校录取最低分是录取结束后形成的结果，不是事先设定的承诺线，因此系统只能输出统计估计，不能预测或保证真实录取结果。

官方依据：[2026年广州市中考志愿填报问答](https://gzzk.gz.gov.cn/gkmlpt/content/10/10811/post_10811628.html)

## 验证

- 原有规则与评分测试：10 项通过。
- 构建数据检查：通过，名额分配记录 27,222 条。
- v2 回归：固定种子可复现、第三/第四批使用年度为 2023—2026、自动方案无同校体系重复、手工同校体系重复能产生提示。
