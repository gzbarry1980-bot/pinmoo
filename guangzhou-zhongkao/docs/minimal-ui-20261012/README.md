# 极简界面改版

日期：2026-10-12（北京时间）

状态：经用户授权，已于2026-10-12 22:14:54（北京时间）发布正式站 `ui-20261012-minimal`，上一版 `ui-20261012-codex-ui` 保留用于回滚。

## 体验变化

- 首页先给四个短入口：按分数生成、目标学校、心仪学校、已有志愿。手机首屏不再放大幅配图和重复的流程说明，学校搜索前置。
- 当前只显示当前步骤：填条件、排志愿、看结果。不删除原字段；高级条件、区域喜好、填写检查等按需展开。
- 结果先看方案评分、最可能去向和风险。导出、打印、评分明细、排序依据及模型说明放在后面。
- 缺保底提醒、资格封顶原因、参考等级待确认、规则暂用年份与完整免责声明保留。评分与录取概率的区别仍在结果旁明确显示。
- 第一批页面缩短重复介绍，特长项目和自主招生入口保留。学校完整档案不精简数据，用户主动查看后仍可详细阅读。

## 首屏文字对比

同一 390×844 视口、默认状态，统计主区域首屏可见文字节点，不含输入框值、下拉选项和隐藏内容：

- 首页：133 → 86，约减少35%。
- 填写页：138 → 64，约减少54%。

这是界面文字量对比，不代表阅读时间或转化率提升。条件表更短后，更多实际控件能够提前出现。
