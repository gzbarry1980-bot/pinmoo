# 学校库与统一志愿工作区改版交接

日期：2026-10-05。状态：本地实现与测试完成，未部署公网；小程序只更新导航/H5入口，未发布或真机验收。

## 入口

- 本地预览：http://localhost:5174/
- 发布构建包预览：http://localhost:5175/
- 首页 → 查学校 / 志愿方案 / 招生信息 / 我的。
- 查学校支持独立搜索、简称、区域与渠道筛选、24条加载、收藏和2—4校对比。
- 学校档案直接地址 `/schools/detail/?id=学校校区ID`；按年度/批次/考生口径查历史，有来源才显示电话与活动。查看学校不要求先填写分数。
- 志愿工作区保留方向、目标校、求证三种起点；核心为第三、第四批。第二批名额分配仍按资格与来源初中启用；第一批以资料查询为主。
- 完整方案保留合理度分值、学校机会、最终去向、风险和具体调整。方向切换/自动补强显示具体替换与变化，不伪造满分。
- 修改会使旧评估过期；支持撤销、另存多方案、两方案比较、匿名JSON导入导出。从结果看学校可回到原结果。
- 本机资料只保存在当前浏览器；不跨设备自动同步。清理浏览器存储可能丢失，请自行导出备份。

## 视觉

参考EdmunHigh的白底、深墨蓝、编辑式标题、留白及校园宽图，改为适合中文工具的三字号系统。图片为AI生成氛围示意图，非真实学校照片。手机底栏不再使用遮挡页脚的旧快捷菜单；对比栏也不再覆盖正文。

新增 `experience.css/js`、`school-service.js`、`workspace-store.js`、`site-shell.js`、`home.js` 及学校/方案/招生/我的路由。增量接入已有 `app.js` 与专项/解锁页；没有修改 `engine.js`、`realistic-sim.js` 或主站 `scripts/build.mjs`。序列号服务和设备上限未改写。
