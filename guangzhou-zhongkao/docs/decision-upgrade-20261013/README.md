## 已实现

- 网页解锁统一为序列号，明确最多两台设备、期限按实际权益；小程序仍沿用原开通入口，不新增收款逻辑。
- 匿名用户可生成草案，先进入第2步查看前三个位置并确认评估；可读简版结论、主要风险和一条完整解释。完整学校表、评分、机会与建议仍按原服务端权益打码。
- 解锁链接带回已保存的方案和原步骤，取消new参数。返回时恢复现有有效缓存；旧模型结果不复用。
- 结果页显示主要模拟情景，包含未被所填志愿录取的情景，避免总挑一所学校当成最可能去向。
- 已解锁用户可用原模型比较估分下限、中心值、上限下的同一份方案。
- 自动调整先展示学校替换、合理度和主要情景的前后变化，家长可保留原方案或采用后重新评估。
- 方案卡直接显示已有评估摘要和主要风险，主入口为继续调整，备份/重命名/移除收进更多操作。
- 学校页用现有资料回答六个常见问题：校区、招生范围、门槛、住宿与费用、特长项目、出口参考。未收录事实保持待核对；未新增未经来源核对的学校事实。
- 使用说明补充浏览器识别、换设备与方案暂不自动同步的边界。

## 模型与检验

- 两种模拟设置共用官方分数段内线性位次估算，修正整个10分段被压到同一点的问题。该估算不是实际一分一位表，也不能据此直接宣称准确率提高。
- 历史年数只计算符合考生类别和范围的记录；其他类别的历史不再提高依据等级。较充分依据要求至少5年，信息不确定较多时降级。
- 完全没有匹配记录的学校返回资料不足，避免通过5%下限虚构机会；结果页不把全无资料显示为100%落选。
- 保留中性/波动模拟假设，并在缺同分/末位信息较多时提示假设占比。尚未用真实个体样本校准50%中性假设。
- 新增跨年门槛检验，按同校区、批次、考生类别、范围，用严格早于验证年的记录估计。验证年分数段仅用于排名换回分数，因此这是已知成绩分布后的条件检验，不是考前预测。
- 2024/2025/2026年分别有62/307/359条有效验证记录；平均绝对门槛偏差约21.2/14.1/18.4分，中位偏差约14.8/10.4/9.1分。不能解释为个人录取预测准确率。历史范围覆盖仍不充分，不自动据此调高机会或收紧区间。
