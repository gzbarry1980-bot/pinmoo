## 2. 需要你提供 / 完成的 6 项凭证

### 2.1 要给我的值

| 变量 | 是什么 | 去哪里拿 | 格式 |
|---|---|---|---|
| `WX_APPID` | 小程序 AppID | 微信公众平台 → 开发管理 → 开发设置 | `wx` 开头共 18 位 |
| `WX_APPSECRET` | 小程序 AppSecret | 同上（重置后旧的立即失效） | 32 位字符串 |
| `WX_MCHID` | 微信支付商户号 | 商户平台 → 账户中心 → 商户信息 | 10 位数字 |
| `WX_MCH_SERIAL` | 商户 API 证书序列号 | 商户平台 → 账户中心 → API安全 → API证书 | 40 位十六进制大写 |
| `WX_MCH_PRIVATE_KEY` | 商户私钥文件 `apiclient_key.pem` | 申请 API 证书时下载（**不要给 `apiclient_cert.pem`**） | PEM 文件路径 |
| `WX_API_V3_KEY` | APIv3 密钥 | 商户平台 → API安全 → 设置 APIv3 密钥 | **32 字节**（32 个 ASCII 字符） |
| `WX_PLATFORM_PUBLIC_KEY` | 微信支付**平台公钥** | 商户平台 → API安全 → 微信支付公钥 / 平台证书导出的公钥 | PEM 文件路径 |

> 两个高频致命错误，自检脚本会拦：
> 1. 把 `apiclient_cert.pem`（商户证书）当成平台公钥 —— 脚本比对指纹，相同直接 FAIL。
> 2. APIv3 密钥不是 32 字节 —— 脚本按 `Buffer.byteLength` 校验，不接受"看起来是 32 个字符"的中文或超长串。

## 5. 失败诊断表

| 现象 | 原因 | 处理 |
|---|---|---|
| 401 `SIGN_ERROR` | 私钥与证书序列号不匹配，或服务器时间偏差 > 5 分钟 | 核对序列号；`ntpdate`/`chrony` 同步时间 |
| `APPID_MCHID_NOT_MATCH` | 商户平台未关联 AppID | 产品中心 → AppID账号管理 → 关联 |
| 下单 503 | `paymentConfigured=false` | 跑 `check-wxpay-config.cjs`，补齐缺项 |
| 登录 503 | 缺 `WX_APPID`/`WX_APPSECRET` | 补齐后重启 |
| 回调 404 | nginx 丢失精确路由 | 检查 `location = /api/pay/notify` 并 reload |
| 回调 429 | 限流未 exempt | 回调路由不得挂 `limit_req` |
| `INVALID_REQUEST` / openid 无效 | openid 不属于该 appid | 用真机该小程序登录拿到的 openid |
| 拉起支付失败 `-1`/`-2` | paySign 错或 prepay_id 过期 | 重新下单；核对 `buildPaySign` 用同一 appid |
| 平台公钥指纹 = 商户证书指纹 | 拿错文件 | 换成微信支付平台公钥/平台证书公钥 |
