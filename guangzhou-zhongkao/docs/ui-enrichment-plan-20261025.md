# 广州中考志愿助手：界面增强规划

日期：2026-10-25。状态：设计规划，尚未修改应用或部署。

## 目标

让系统更有品牌感、学校氛围和清晰的操作层次，同时保留精简文案。不通过恢复长说明、增加入口数量或夸大数字来制造丰富感。

依据：当前源码，以及 `flow-upgrade-20261025/online-browser-r3/` 的最近发布验收截图。本次没有重新进行线上界面验收。

## 现状判断

- 已有生成、查校、目标校、心仪校排序、评估等功能，不需要再堆功能模块。
- 简化样式隐藏了手机端主图，许多区域仅剩白底、边框和正文，视觉层次被压平。
- 首页“查学校”入口与下方查校搜索重复；需要统一成一个明确的辅助任务区。
- 结果中“方案合理度”和录取机会必须有独立的视觉表达，避免把91分读成91%的录取机会。

## 页面规划

| 页面 | 主视觉与结构 | 首要动作 | 保留的边界 |
|---|---|---|---|
| 首页 | 品牌区、短幅校园插画、一个主要开始按钮；查学校和目标校为两个辅助入口 | 开始生成志愿 | 第一批特长/自招、第二批名额分配放辅助区，不抢主流程 |
| 填写条件 | 分数范围、报考条件、选校偏好三组；图标、浅色分区、已填标签 | 生成草案，进入排志愿 | 资格未知仍需确认，不默认视为符合 |
| 排志愿 | 第三批和第四批分组；志愿编号、学校名称/校区、同口径参考、冲稳保标签 | 确认志愿，查看评估 | 生成后停在第二步；更换学校、上移、下移为明确按钮；拖动只是辅助 |
| 评估结果 | 方案合理度、可能去向、当前最需调整项三层；细节折叠 | 调整当前重点问题 | 评分不是录取概率；区间为统计估计，资料不足不填假值 |
| 学校列表 | 学校与校区标题、区域/性质、同考生口径门槛、独立升学参考摘要 | 查看学校 | 升学指标保留年份、人数/比例、学校/班型口径，不做学校质量总榜 |
| 学校详情 | 校园视觉；能否报、历年门槛、住宿、费用摘要；历史趋势和分节资料 | 加入心仪校或志愿 | 缺失与未核实明确显示；不把历史学费当作当年收费 |
| 我的方案 | 最近方案、估分区间、修改时间、是否需要重算；编辑与查看分开 | 继续修改或查看结果 | 保留方案ID、原步骤、筛选与返回位置 |

## 视觉规范

- 继续使用深蓝和品沐橙；浅米白作为页面底色，少量青绿色用于辅助表达。
- 标题24px、正文16px、备注14px，保持三档字号；通过字重、留白、对齐建立层级，不再增加字号档位。
- 主按钮实心、次按钮描边、文字链接带清楚的箭头或下划线；普通说明不做伪按钮。
- 手机主按钮至少48px高，其他触控目标至少44px；底部操作栏与导航不叠压内容。
- 先用分组、间距、分隔线，再用浅底色；减少每个模块都套一层白卡的做法。
- 冲刺、匹配、保底同时使用文字和颜色；保底只是模型分类，不表示保证录取。
- 动效只服务于选中、切换、排序和保存反馈，约150—250ms；遵循减少动画偏好。
- 首页配图在手机端限制为短幅约120—160px，主动作在390×844首屏可见。概念稿的插画比例与实际字号落地时需要重新量测，不能直接把整张稿当页面背景。

## 配图与信息图

1. 首页：原创通用广州校园氛围插画，不标成某所真实学校。
2. 操作引导：统一线性图标表达分数、学校、排序、评估，不复制一张配图到所有模块。
3. 学校资料：只用有授权、能确认对应校区的照片；缺图时采用中性插画或无图布局，不生成假校园实拍。
4. 历年门槛趋势：只连接同批次、同类别、同校区的可比记录；缺年留空，不能伪造连续数据。
5. 录取去向：只使用同一组模拟情景计算的方案去向分布，不把单校机会相加；区间和资料不足状态保留。
6. 方案合理度：使用“XX / 100”与短释义“评价填法，不是录取概率”，不用容易误解为百分比的巨大圆环。

## 三个概念方向

本次已生成三张独立首页概念图，按聊天中展示顺序选择。它们是设计探索，不是已完成页面。部分生成图自动增加了文字或图标，开发前必须依据上述规范校正。

- 第一张：校园氛围与明确开始入口。
- 第二张：志愿结构示意与工具型工作区。
- 第三张：成长路径插画与估分输入前置。若采用，首页估分只带入第一步，仍需完成考生条件后才能生成方案。

无论选择哪张，功能路径不重做，录取引擎、序列号与设备绑定不因视觉改版而更改。

## 实施顺序

1. 选择一个视觉方向，校正首屏插画比例、短文案和按钮层级。
2. 先做首页、排志愿、评估结果三屏，确定统一组件。
3. 扩展到学校列表、详情、条件填写和我的方案；保留当前返回与上下文机制。
4. 验收桌面1440px、手机390px及窄屏360px：按钮可见、字段对齐、无横向溢出、底部不遮挡、键盘可用。
5. 验收查校返回、生成停在第二步、修改/结果分别进入正确步骤、失效方案重算、未解锁预览与解锁返回。
6. 单独核对数据缺失、无同类别记录、未知资格、加载失败、空方案、保存成功等状态。
7. 本地验收后，在用户授权下按现有显式文件清单和可回滚流程发布。

## 本轮不做

- 不增加新交易入口，不改付费或序列号服务。
- 不把所有会员资料重新做成独立资料库。
- 不用装饰动画掩盖加载，不增加自动轮播横幅。
- 不调整概率或人为把方案分数提高。
- 不因为有新视觉稿就声称预测更准确或真实家长验收通过。
