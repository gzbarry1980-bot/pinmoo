# 第一批实施交付：政策年份与学校事实

日期：2026-10-18（北京时间）。本轮本地实现、构建和浏览器验收已完成；未部署正式站、未提交／推送Git，未修改收款、序列号或设备绑定。

## 已实现

1. **2027政策首轮适配。** 核对2027—2029正式改革原文，建立政策事实与差异表；分开报考年份、政策框架年份、年度细则年份、录取数据年份及分数分布年份。默认仍预测2027，成绩分布和学校最新录取仍使用实际2026记录。
2. **预测依据说明。** 首页、条件页、结果依据、数据覆盖页采用一致说明。新旧政策周期的预测显示政策过渡原因，参考等级降为需谨慎；共同说明集中到结果摘要，不在每所学校后重复长段文字。现有单校机会和整份志愿去向仍由同一组情景计算，没有因政策提示人为提高机会或评分。模型结果版本2.3，旧结果提示重算，旧模型缓存不直接恢复为当前评估。
3. **20校区事实复核。** 对已保存正文、原始内容哈希和上轮已核对的班型表交叉检查。17项历史住宿费找到明确“元／学期”文本，3所未明确费用保持空值。补出广雅花都“标准7人间／特色4人间”和六中花都“文章300人／班型表350人”的适用范围或数字差异，连同已有差异在学校页提示。历史住宿、费用及班型仍不写入当年主表。
4. **出口成绩扩充。** 逐行查看上次保存的第三方原表截图，将独立出口成绩表从1条扩充为63条学校档案、132条年度记录，另有1条铁一多校区合计（3个年度）。学校列表与详情直接显示事实；人数、比例、重点班和多校区合计明确区分。
5. **差异与缺项保留。** 原表与会员文章中省实、二中、广附、执信等数字或范围不同，保留差异及来源。海实、广外外校、为明、广理实验、海珠中学5个标签尚待准确学校／校区对应；没有强行关联。第三方数据的学校原始公告与分母仍未核实，不作为学校质量总榜或录取模型输入。
6. **历史资料补缺推进。** 重新确认2021第三、第四批、分数段及2022第三批4个官方页面，确认共7张表格图片，列入逐图转录队列。尚未完成转录或写入模型，原有缺失说明保留。
