# 2027—2029政策首轮适配核对

核对日期：2026-10-18（北京时间）。适用于网页版首轮适配。新年度计划、招生简章、控制线与具体投档细则仍按各自来源逐项核对，不把政策框架当作完整年度招生数据。

原文：[广州市教育局关于印发2027—2029年深化高中阶段学校考试招生制度改革实施意见的通知](https://gzzk.gz.gov.cn/zwgk/tzwj/content/post_10298205.html)，2025-06-05发布。

解读：[广州市教育局正式发布2027—2029年中考改革方案](https://jyj.gz.gov.cn/yw/jyyw/content/post_10298181.html)。

2026依据：[2026报考指南](https://gzzk.gz.gov.cn/attachment/8/8027/8027351/10816553.pdf)。

## 数据契约与兼容

`latestPolicyYear:2026` 仅为旧代码的兼容字段，保留旧年度细则含义。新增 `latestAnnualRulesYear:2026`、`latestPublishedFrameworkYear:2027`、`latestAdmissionYear:2026`、`latestScoreDistributionYear:2026`、`defaultForecastYear:2027`。

网页版的成绩分布、学校排序、批次取数和默认预测入口已改用各自的年份。模型结果版本升为2.3，旧2.2缓存不直接复用；保存的旧评估保留为历史记录并提示重算，旧评估不用于两方案的当前结果比较。

小程序原生服务内的旧引擎属于后续真机与同步验收范围，本轮不把网页浏览器检查写成小程序已验收。
