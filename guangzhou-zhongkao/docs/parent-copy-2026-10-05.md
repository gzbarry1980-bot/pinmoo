# 家长易读文案优化

日期：2026-10-05。状态：本地已实现，未同步公网。本轮是表达优化，不是模型校准或准确率提升。

## 文案原则

日常操作用易懂表达；招生规则保留专业名称并解释。历史依据、单校机会、最终去向三个概念分开说明，不用更肯定的措辞掩盖数据缺失，不把保底说成保证录取。

| 原表达 | 家长看到的表达 |
| --- | --- |
| 中置信度 | 历史依据：一般；解释数据年数、补估和波动仍有局限，不是录取机会中等 |
| 高/低置信度 | 历史依据：较充分 / 较少或波动较大 |
| 槽位利用 | 志愿是否填全 |
| 中心分值 | 正常发挥估分 |
| 年际难度 | 不同年份的考试难度 |
| 波动压力测试 | 额外考虑发挥波动 |
| 单校把握 / 最终去向 | 这所学校的机会 / 最终录到该校的机会 |
| 同口径 | 可比较的；解释同校区、批次、考生类别和招生范围 |
| 系统自动补强 | 帮我自动调整 |
| 模型口径与数据局限 | 怎么算的？哪些情况要谨慎看？ |

## 覆盖

- 首页、学校库/档案/比较、方案入口、个人方案、方向/目标/检查页、专项卡片的常见术语。
- 方向与结果页新增折叠的“这些结果怎么看”；解释历史依据、两类机会、冲稳保、梯度保护、末位志愿、位次和同分序号。
- 学校档案新增最低分、末位志愿和同分序号说明。
- 志愿行注明参考数据年度，用“比估分高/低几分”替代“分差偏冲/偏稳”，避免只凭分差误判机会。
- 官方来源、免责声明、序列号管理和底层模型字段不作口语化改写；专业术语在解释中仍保留。
