# 下一阶段计划与未完成项清单

日期：2026-10-18（北京时间）

本次为项目盘点和规划，不修改线上功能。依据当前工作区、2026-10-15发布回执、数据清单、历史验收记录及本次读取的官方政策编制。公开站本次读取失败，不能据此判断站点故障；上线状态引用已保存的10月15日成功回执，不声称完成了10月18日整站复验。

## 本阶段目标

让家长快速回答三件事：这所学校是否适合孩子；这份志愿顺序是否合理；估分变化后有哪些风险。主流程继续以第三、第四批为中心；第一批与第二批提供对应资料和资格辅助。

保留已完成的四种使用方式、三步填报、学校搜索收藏对比、序列号解锁和简版体验。学校资料融入学校档案和选校环节，首页不新增独立会员资料库。

## 已交付，不重复建设

- 10月15日已发布 `ui-20261015-member-school-references`：20个省市属学校／校区的校园、住宿与培养方向参考，17条2025班型参考。发布回执记录12个更新文件、95个保留文件，20项公开浏览器检查通过。
- 原始会员正文、图片及未复核识别数据留在研究目录，公开站显示整理后的学校事实及来源。
- 三步流程“填写条件 → 调整志愿 → 查看结果”、调整前后对比、估分上下限比较及解锁后返回方案已有实现，后续通过实际使用找问题。
- 已有按校区、批次、考生类别、范围匹配的跨年门槛检验，不能把它当作个人录取概率的准确率。

## 新增最高优先项：2027年度适配

官方已于2025年6月5日发布2027—2029年中考改革方案：总分仍为810分，部分科目分值、随迁子女招生比例上限和第一批次设置等有调整；名额分配、自主招生、特长生、填报志愿等年度文件按年度节点发布。

官方依据：[广州市教育局正式发布2027—2029年中考改革方案](https://jyj.gz.gov.cn/yw/jyyw/content/post_10298181.html)。

当前 `manifest.latestPolicyYear` 仍为2026，页面以“新年度规则未公布前，暂按2026规则模拟”概括未来年度，表达过于笼统。需要区分已公布的改革政策与尚待逐项检查的年度细则。

实施必须分开三个年份：目标报考年份、已核对政策年份、最新实际录取数据年份。不能仅把2026改为2027：现有代码还用该字段读取分数段并设置默认预测年份，直接替换会误用不存在的2027成绩分布或跳到2028预测。

## 分批交付顺序

1. **批次一：依据修正与已有资料补齐。** A01、A02、A04先完成，A03同步推进。交付政策差异表、20校区核对表、首批出口成绩档案以及缺失清单。验收通过再发布对应范围。
2. **批次二：各区扩容与选校体验。** B01按批收录，B02把事实带到家长正在选校的位置；C01/C02完成发布与源码交接检查。每批可单独验收，不等全市资料齐全才交付。
3. **批次三：实际使用与预测检验。** B03/B05的样本和家长体验可从第一批开始准备；B04需合格样本，B06需真机条件。依据真实失败修正，形成新旧版本对照报告。
4. **批次四：持续使用能力。** 有真实使用反馈后再决定C03/C04，避免先扩大入口和功能数量。

这是执行顺序，不承诺固定日历工期。会员登录、原始公告、完整案例和真实参与者会影响周期；每批汇报已完成、缺失、阻塞与可发布范围。

## 本阶段产品边界

- 不为提高表面评分把生成方案统一加到80／100分；评分应反映同一考生条件下顺序、资格、风险结构与偏好是否合理。
- 不把高考出口成绩称为学校“加工能力”的精确衡量；生源和统计口径差异需要保留。
- 不复制整个会员平台；继续按学校／校区提炼可核对事实。
- 不承诺精确录取概率、包录取、免费住宿或未公布的招生计划。
- 收款仍由用户处理。本阶段重点是数据、规则、选校理解和流程完成度，不代开支付、不创建交易。
