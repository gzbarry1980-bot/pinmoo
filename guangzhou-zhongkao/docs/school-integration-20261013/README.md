# 学校信息融合方向修正

2026-10-13，北京时间。用户明确：会员资料作为整理学校信息的来源，学校事实融入原有系统，不建立独立资料库或迁移整个会员内容平台。

## 本次修正

- 首页、学校库、我的、招生数据页与页脚撤下“中考资料库”入口。
- 学校页撤下通用学校目录、签约目录、政策目录链接，保留原有学校概况、六项重点信息、历年录取、特长与自招、开放日和出口成绩等学校内页面。
- 旧 `/resources/` 书签转到 `/schools/`，不再展示资料分类模块。
- 公开构建排除 `data/member-resources.json`、`resource-library.js`、`resource-library.css`、`resources/resources.js`。来源网址备份至 `research/member-resources-20261013/source-links.json`，研究目录不发布。
- 本次不增加未经读取核对的学校事实，不改变录取模型和序列号服务。

## 学校事实整理规范

按学校/校区匹配后，把资料事实写入对应领域：校区介绍与特色 → 学校概况；学费与住宿 → 对应字段；特长与自招 → 项目/资格/简章/历年成绩；开放日 → 活动记录；出口成绩 → 分年份独立参考。

每条事实必须带学校主键、校区范围、年份、来源网址和统计口径。学校自报或第三方整理的出口成绩不进入录取机会或方案评分。普通志愿、特长文化门槛、自招合成成绩不可混成同一种分数。资料空白不推定为0、免费或可住宿。

10类会员目录仍保留为内部整理线索；当前没有取得学校介绍正文，不把目录标题当作学校事实。2026-10-13再次检查文档读取连接，返回没有连接的会话。因此本次完成产品方向修正，未完成新会员正文逐校融合。
